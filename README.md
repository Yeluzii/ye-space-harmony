# 野空间-鸿蒙端

## 项目概述

野空间是一个基于鸿蒙系统的社交应用，主要功能包括用户登录注册、动态发布、好友管理和个人中心等。

## 技术栈

- 鸿蒙ArkTS开发语言
- ArkUI框架
- Axios网络请求库
- 本地存储(AppStorage/PersistentStorage)

## 开发内容

### 1. 项目初始化

1. 创建鸿蒙项目工程
2. 配置项目基本信息(module.json5)
3. 配置网络权限(ohos.permission.INTERNET)
4. 安装依赖包(@ohos/axios)

### 2. 网络请求模块开发

1. 创建axios实例(axiosInstance.ets)
   - 配置基础URL和超时时间
   - 设置请求和响应拦截器
   - 处理认证token的自动添加
   - 统一错误处理和提示

2. 定义API接口
   - 登录相关接口(passwordLoginApi, codeLoginApi, sendCodeApi)
   - 用户相关接口
   - 动态相关接口
   - 好友相关接口

3. 定义数据模型
   - 用户模型(User.ets)
   - 动态模型
   - 好友模型

### 3. 用户认证模块开发

1. 创建登录页面(Login.ets)
   - 实现账号密码登录表单
   - 实现手机号验证码登录表单
   - 添加表单验证
   - 实现登录状态管理

2. 创建注册功能
   - 实现验证码发送功能
   - 实现注册表单

3. 实现用户状态持久化
   - 使用PersistentStorage持久化用户信息
   - 使用AppStorage在应用内共享用户状态

### 4. 主界面架构开发

1. 创建启动页(Start.ets)
   - 实现启动页倒计时功能
   - 添加自动跳转逻辑

2. 创建主布局页面(Layout.ets)
   - 实现底部导航栏
   - 创建页面切换逻辑
   - 集成各个主功能页面

3. 创建导航系统
   - 使用NavPathStack管理页面导航
   - 实现页面间的跳转和传参

### 5. 核心功能模块开发

1. 首页模块(HomePage.ets)
   - 展示推荐内容
   - 实现刷新和加载更多功能

2. 动态模块(PostPage.ets)
   - 实现动态列表展示
   - 创建发布动态功能
   - 实现动态详情查看

3. 好友模块(FriendPage.ets)
   - 实现好友列表展示
   - 创建好友搜索功能
   - 实现好友详情查看

4. 个人中心模块(Mine.ets)
   - 展示用户个人信息
   - 实现设置功能
   - 实现退出登录功能

### 6. 组件库开发

1. 创建底部导航栏组件(TabBar.ets)
   - 实现可复用的导航栏结构
   - 支持自定义图标和文字

2. 创建媒体查看器组件(MediaViewer.ets)
   - 实现图片和视频的查看功能
   - 支持手势缩放和滑动切换

3. 创建其他通用组件
   - 加载提示组件
   - 确认对话框组件

### 7. 样式和资源管理

1. 配置应用图标和启动图
2. 添加字体资源并注册
3. 配置颜色和字符串资源
4. 实现深色模式适配

### 8. 测试和优化

1. 进行功能测试
2. 优化页面加载性能
3. 处理异常情况和边界条件
4. 进行内存和性能优化

### 9. 构建和发布

1. 配置签名信息
2. 构建生产版本
3. 进行真机测试
4. 发布到应用市场
